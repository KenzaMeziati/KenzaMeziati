# Optimizing Production Performance through Predictive Maintenance Insights

**Capstone project in collaboration with Sidel (2025)**

## ⚠️ Data Confidentiality

The raw data used in this project is the property of Sidel and cannot be shared publicly. This repository contains the **code and methodology only**.

## What's inside

- Ggle Colab file (EDA, feature engineering, modeling)
- Python scripts (training, prediction, SHAP analysis)

## Technologies used

- Python, Pandas, Scikit-Learn, XGBoost, Random Forest, SHAP, Statistical Hypothesis Testing

## Key contributions (achieved on Sidel's internal data)

- Performed correlation analysis between failure events and performance metrics to identify degradation patterns.

- Engineered features from temporal alarm data to detect early warning signals.

- Assessed the impact of disruptive events (e.g., Bottle Burst) on Overall Equipment Effectiveness (OEE) through statistical testing.

- Built and evaluated interpretable ML models (Random Forest, XGBoost) for failure prediction.

- Utilized SHAP analysis for model explainability, providing clear reasoning for predictions to support engineer decision-making.
